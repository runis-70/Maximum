# Maximum

Maximum - это проект мини-приложения в Max для досуга и развлечения. Разработка сервиса для афиш событий, волонтёрства,
туризма или спорта — от поиска до покупки билетов. Проект делается по заказу хакатона Max для Минобрнауки.

Сфера досуга объединяет разные пользовательские сценарии: культурные и спортивные события, туризм, волонтерство, городские активности и другие возможности для
проведения свободного времени. В этих процессах участвуют жители и туристы, организаторы мероприятий, учреждения культуры, спортивные организации, волонтерские
объединения и другие участники отрасли.

## Установка проекта (Windows)
У вас должны быть установлены [зависимости проекта](#зависимости)

1. Клонирование репозитория или через программное обеспечение GitHub

```git clone https://github.com/runis-70/Maximum.git```

2. Переход в директорию  ```src```
3. Находим файл ```Maximum.sinx``` и открываем его через ```Visual Studio```

4. Ожидаем успешной загрузки и сборки проекта

5. Все готово к дальнейшей работе !

## Описание коммитов
| Название | Описание                                                        |
|----------|-----------------------------------------------------------------|
| build	   | Сборка проекта или изменения внешних зависимостей               |
| sec      | Безопасность, уязвимости                                        |
| docs	   | Обновление документации                                         |
| feat	   | Добавление нового функционала                                   |
| fix	   | Исправление ошибок                                              |
| perf	   | Изменения направленные на улучшение производительности          |
| refactor | Правки кода без исправления ошибок или добавления новых функций |
| revert   | Откат на предыдущие коммиты                                     |
